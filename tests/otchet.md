## 3. Найденные дефекты (Bug Report)

### DEF-01 — Critical: нет звука в наушниках ведущего

| Поле | Значение |
| --- | --- |
| Серьёзность | Critical |
| Приоритет | High |
| Модуль | Звуковой тракт (ТС-1) |
| Окружение | Пульт [модель], наушники [модель] |
| Статус | Закрыт |

**Шаги воспроизведения:**
1. Подключить наушники ведущего к выходу пульта.
2. Включить мониторинг канала микрофона.
3. Произнести контрольную фразу.

**Фактический результат:** звук в наушниках отсутствует.
**Ожидаемый результат:** голос ведущего слышен без задержки.

**Причина:** кабель наушников вставлен в разъём не до конца (контакт ослаблен).
**Решение:** переподключить кабель; в предэфирный чек-лист добавлен пункт «проверить фиксацию всех разъёмов»; в регламенте — резервные наушники.

---

### DEF-02 — Major: пауза 8 минут при отключении питания стойки

| Поле | Значение |
| --- | --- |
| Серьёзность | Major |
| Приоритет | High |
| Модуль | Отказоустойчивость (ТС-4) |
| Окружение | Стойка питания пульта, программа вещания |
| Статус | Закрыт с оговоркой (требуется ИБП) |

**Шаги воспроизведения:**
1. Начать запись эфира.
2. Отключить питание стойки на 60 секунд.
3. Замерить время до восстановления вещания.

**Фактический результат:** автоплей включился через 45 сек (по регламенту ≤60 сек), но полное восстановление прямой трансляции заняло 8 минут — пауза превысила лимит 3 минуты.
**Ожидаемый результат:** восстановление эфира не дольше 3 минут.

**Причина:** перезапуск и калибровка пульта после потери питания не автоматизированы.
**Решение:** автоплей сократил паузу, но причина — незащищённое питание. Требуется ИБП для стойки (внесено в рекомендации); повторный прогон TC-401 после установки ИБП.

### DEF-03 — Major: слушатели не могут дозвониться при пиковой нагрузке

| Поле | Значение |
| --- | --- |
| Серьёзность | Major |
| Приоритет | Medium |
| Модуль | Интерактивы (ТС-6) |
| Окружение | Телефонная линия студии |
| Статус | В работе |

**Шаги воспроизведения:**
1. Инициировать 5 одновременных звонков в студию.
2. Проверить, сколько вызовов принято или поставлено в очередь.

**Фактический результат:** 2 из 5 звонков сбрасываются, очередь звонков не настроена.
**Ожидаемый результат:** все звонки принимаются или ставятся в очередь с автоответчиком.

**Причина:** ограничение по количеству линий; очередь звонков не сконфигурирована.
**Решение (в работе):** добавить линии, настроить очередь и автоответчик с инструкцией для слушателя.
